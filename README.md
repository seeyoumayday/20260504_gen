# AのBの中で ジェネレーター (A in B Generator)

「AのBの中で ah」という特定のフレーズパターンを生成する、シンプルでスタイリッシュなWebアプリケーションです。キーワードを入力するだけで、幻想的で詩的なフレーズをワンクリックで自動生成します。

## ✨ 特徴 (Features)

- **スマートな単語分割**: 「の」を含む言葉を入力すると、自動的に「A」と「B」に分割して歌詞を構築します。（例: 「夜の海」→ A: 夜 / B: 海）
- **フォールバック機能**: 「の」を含まない言葉を入力した場合は、入力された言葉を「A」とし、「B」にはデフォルトで「光」が適用されます。
- **ダークモード・グラスモーフィズムデザイン**: 洗練されたダークトーンを基調とし、ガラスのような半透明のカードUI（グラスモーフィズム）を採用。
- **パーティクルアニメーション**: 背景にCanvasを使用した、ふわふわと浮かぶ幻想的な光のパーティクルを描画。
- **ワンクリックコピー**: 生成されたフレーズは、コピーボタンからワンクリックでクリップボードに保存可能。
- **レスポンシブ対応**: スマートフォンやタブレットでも綺麗に表示されるよう最適化されています。

## 🛠 使用技術 (Technologies)

Reactなどのフレームワークに依存せず、ブラウザ標準の技術のみで軽量に構築されています。

- **HTML5**: セマンティックな構造
- **CSS3**: カスタムプロパティ（変数）、Flexbox、アニメーション、グラスモーフィズム（`backdrop-filter`）
- **Vanilla JavaScript**: DOM操作、クリップボードAPI、Canvas 2D APIによるパーティクル描画
- **Web Fonts**: Noto Serif JP（見出し・明朝体）、Noto Sans JP（本文・ゴシック体）

## 🚀 使い方 (How to Use)

1. このリポジトリのファイル（`index.html`, `style.css`, `app.js`）を同一のフォルダに配置します。
2. ブラウザで `index.html` を開きます。（ローカルサーバー経由でも、そのままファイルをダブルクリックしても動作します）
3. 中央のテキストボックスに好きなキーワード（例：「朝の光」「夜の海」「冬の星」など）を入力します。
4. 「生成」ボタンを押すか、Enterキーを押すとフレーズが生成されます。
5. 気に入ったフレーズは右下の「コピー」ボタンからコピーできます。
